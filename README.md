## Trabajo realizado durante el proyecto

Durante el desarrollo del proyecto se trabajaron diferentes actividades por semana, aplicando conceptos de Programación III, manejo de ramas en GitHub, pruebas, integración con base de datos y documentación del avance realizado.

## Semana 1: Configuración inicial y revisión del proyecto

En la primera semana se trabajó en la configuración inicial del proyecto, revisión de la estructura de carpetas y preparación del entorno de desarrollo.

### Actividades realizadas

- Se revisó la estructura general del proyecto.
- Se configuró el entorno de trabajo local.
- Se verificó que el proyecto compilara correctamente.
- Se trabajó con Git y GitHub para el manejo de ramas.
- Se realizaron pruebas iniciales para confirmar que el proyecto funcionara correctamente.

## Semana 2: Desarrollo de funcionalidades y pruebas

En la segunda semana se continuó con el desarrollo de funcionalidades del proyecto, realizando cambios en el código y validando su funcionamiento mediante pruebas.

### Actividades realizadas

- Se trabajó en la implementación de partes asignadas del proyecto.
- Se revisaron errores de compilación y se corrigieron problemas encontrados.
- Se ejecutaron comandos de construcción del proyecto para verificar que no existieran errores.
- Se realizaron commits con los avances correspondientes.
- Se subieron los cambios al repositorio remoto mediante ramas de trabajo.

## Semana 3: Integración con MongoDB y pruebas de repositorio

En la tercera semana se trabajó la parte relacionada con MongoDB, enfocada en la integración del repositorio y la validación de pruebas.

### Actividades realizadas

- Se trabajó la rama `feature/C9-mongo-integration-tests`.
- Se creó la prueba `MongoTreeRepositoryTest`.
- Se validó el funcionamiento del repositorio `MongoTreeRepository`.
- Se comprobó la integración entre Spring Boot y MongoDB.
- Se realizó commit y push de los cambios al repositorio remoto.
- Se dejó preparada la rama para crear el Pull Request correspondiente.

## Parte trabajada personalmente

Mi aporte principal fue trabajar en la integración y validación del repositorio de MongoDB, asegurando que el proyecto pudiera guardar y consultar información mediante pruebas de integración.

También participé en la revisión del proyecto, ejecución de comandos, corrección de errores, creación de ramas, commits y subida de avances al repositorio de GitHub.
